# utm 万能チューリングマシン

## 2状態3記号チューリングマシン

- [Wolfram's 2-state 3-symbol Turing machine](https://en.wikipedia.org/wiki/Wolfram's_2-state_3-symbol_Turing_machine)

### ビルド

```console
stack build utm:exe:utm-2-3
```

### 起動

```console
stack exec -- utm-2-3
```
起動直後
```
UTM(2,3): <Enter>で1ステップすすみ、`C`のキーと<Enter>で停止するまで進む。
     0: _________________________________________________________________________________________________________________________
                                                                    ^                                                            

```
初期状態のテープが表示される。テープは本来左右に無限につづくのであるが、表示は、初期のヘッド位置から左へ60セル、右へ60セルだけ表示している。

- 記号`O`(0)に対応している部分は空白文字で背景は背景色を反転
- 記号`I`(1)に対応している部分は空白文字で背景は黄色
- 記号`Z`(2)に対応している部分は空白文字で背景は赤色

で表示されるようにしてある。テープの左側に現れる数字はステップカウンターの値である。
テープの次の行には`^`がひとつだけ現れる。これがそのときのヘッド位置をしめしている。

このマシンには、停止状態がないのであるが、ヘッドが121桁の表示範囲の端に到達したときにマシンの動きを止めるようにしてある。
この設定では、6008ステップで停止する。
